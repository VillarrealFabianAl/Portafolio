Fabian Villarreal — Portfolio Website

Includes the current website and all 18 adapted activities, with the latest typography and dark-mode updates.

Publish: upload all files and folders together to a static web host. index.html belongs at the website root.

Local preview: from the extracted folder run python -m http.server 8000, then open http://localhost:8000. A local web server is needed for the activity catalog.

This package contains no credentials or hosting access settings. Configure access with your hosting provider.
